# homo 语言手册

homo 是一门用 inm 梗作关键字的小型编程语言。它不直接解释执行，而是先翻译成 C++17，再交给系统里的 C++ 编译器编译成原生可执行文件。Windows 和 macOS 都能运行。

- 编译器：`homo.py`（词法、语法、名字检查、类型推导、inm 解析、C++ 代码生成、命令行入口）
- 运行时：`homo_runtime.hpp`（值类型、运算、内置函数、输出、源码位置映射）
- 桌面编辑器：`homo_editor.py`（Windows / macOS 原生窗口，多文件项目，不再需要浏览器）
- 打包脚本：`build_macos.sh` / `build_windows.bat`

```text
homo.py            编译器 + 命令行
homo_runtime.hpp   C++ 运行时
homo_editor.py     桌面编辑器
assets/            应用图标（原网页左上角 logo）
build_macos.sh     打包成 macOS .app
build_windows.bat  打包成 Windows .exe
```

它带有一点玩笑性质，但语言本身是完整的：动态类型、块级作用域、数组、字符串函数、函数默认参数与可变参数、类与对象、递归、四种循环、多分支、多文件 inm 导入。仓库里的 `quicksort.homo`、`variadic.homo`、`minesweeper.homo` 都是可以直接运行的真实程序。

> 2.0 起不再使用网页版编辑器：原来的 `app.py` / `index.html` 已移除，`homo_editor.py` 是唯一编辑器入口，并通过 PyInstaller 打包成 Windows / macOS 桌面程序。

## 快速开始

需要 Python 3.9+、Tk（Windows 官方 Python 和 python.org 的 macOS Python 都自带），以及一个支持 C++17 的 C++ 编译器。编译器不是 Python 包，需要单独安装：

- **macOS**：`xcode-select --install`（安装 clang++）。
- **Windows**：安装 MinGW-w64（例如 MSYS2 的 `mingw-w64-x86_64-gcc`，把 `g++.exe` 所在目录加入 PATH），或安装 Visual Studio Build Tools 的「使用 C++ 的桌面开发」。编辑器会自动查找 `g++`、`clang++`、`cl`，也会用 `vswhere` 找 MSVC。

### 桌面编辑器

```bash
python3 homo_editor.py                         # 直接打开
python3 homo_editor.py .                       # 打开当前项目文件夹
python3 homo_editor.py main.homo               # 打开单个主程序
```

Windows 上把 `python3` 换成 `py -3` 或 `python`。界面里「打开文件夹」可以载入整个项目，左侧文件树里双击 `.homo` 编辑，`Ctrl/⌘+R` 编译运行。详见[桌面编辑器](#桌面编辑器)。

最小的程序：

```homo
会员制餐厅(){
    脱出("哼哼哼啊啊啊啊啊")噗叽啪
    (0)人幸终
}
```

保存为 `hello.homo`，然后：

```bash
python3 homo.py hello.homo --run
```

输出：

```
哼哼哼啊啊啊啊啊
```

也可以把翻译结果直接打印出来：

```bash
python3 homo.py hello.homo > hello.cpp
```

### 命令行参数

```
python3 homo.py [源文件] [-o 输出路径] [-I 目录] [--run] [--check] [--keep]
```

| 参数 | 作用 |
| --- | --- |
| 不写源文件 | 从标准输入读源码，向标准输出打印 C++ |
| `-o PATH` | 编译并把可执行文件复制到 `PATH` |
| `-I DIR` | 追加 `inm` 的搜索目录，可以写多次 |
| `--run` | 编译后立即运行 |
| `--check` | 只做词法、语法、名字和 inm 检查，不调用 C++ 编译器 |
| `--keep` | 保留临时构建目录，并打印它的路径 |

主文件的 `inm` 默认先在同目录找 `.homo`，再在 `-I` 目录里找；显式 `.inm` 会报错。

注意 `--run` 的输入行为：只有当标准输入是终端时，程序才会继承终端、可以交互输入。用管道或重定向喂输入时（例如 `echo 1 | python3 homo.py x.homo --run`），子进程的标准输入会被立刻关闭，`读入` 读到 EOF、`读行` 读到空串。需要脚本化输入时，先 `-o` 生成可执行文件再单独运行它：

```bash
python3 homo.py minesweeper.homo -o /tmp/ms
/tmp/ms
```

## 多文件与 inm

`inm` 用来引用其他 `.homo` 文件。旧的 `import` 关键字和 `.inm` 声明文件已经废除。

```homo
inm 数学
inm 计数器 from 类定义
```

两种写法：

- `inm 数学`：引用同目录的 `数学.homo`，文件里的函数、类、全局变量都会合并进来。
- `inm 计数器 from 类定义`：只引用 `类定义.homo` 里定义的 `计数器` 类，不引入该文件的其他函数、全局变量或其他类。

### 文件名写法

```homo
inm 库                    // 找同目录的 库.homo
inm 库.homo               // 明确写后缀
inm "lib/工具.homo"       // 用引号写相对路径或绝对路径
inm ./lib/工具.homo       // 点、斜杠可以直接连写
inm 工具 from lib/工具.homo
```

- 不带后缀时自动补 `.homo`。
- 显式写 `.inm` 会报错：`不再支持 .inm 文件；inm 只能引用 .homo 文件`。
- `inm` 路径先相对于当前文件所在目录解析，再搜索 `-I` 目录。
- `inm 类名 from 文件名` 里的类名和文件名之间必须写 `from`。
- 同一个文件不能被同一个程序同时“整体 inm”和“只 inm 某个类”，会报错。

### 合并规则

- 整文件 `inm` 后，文件里的函数、类、全局变量全部可见。
- 选择性 `inm 类名 from 文件` 只带入这个完整的类定义；目标文件顶部的 `inm 其他文件` 不会被加载，其他类、函数、全局变量都不可见。
- 只有整文件 `inm 文件` 时，才会同时加载该文件里的 `inm` 依赖。
- 同一个 `.homo` 被多条路径或多次 `inm` 时只加载一次。
- 同一个文件里的同一个类被多次选择性引用时只加载一次；不同类可以分别引用。
- 不允许循环 `inm`：`检测到循环 inm：a.homo → b.homo → a.homo`。
- 全局变量按依赖顺序初始化：被 `inm` 的文件先初始化，主程序后初始化。
- 函数、类、全局变量重名会报重复定义。
- 入口函数必须是主程序 `.homo` 里的 `会员制餐厅`；没有就报“没有主函数入口”。

### 在桌面编辑器里

点运行时，编辑器会先自动保存所有**已有文件名**的修改，再编译运行。没有设置主程序时，会直接运行当前 `.homo` 或未命名缓冲区，不需要先保存或设为主文件；未命名缓冲区保持未保存状态。左侧文件树只显示 `.homo`；工具栏的「主程序」显示当前入口。

## 词法规则

### 标识符与关键字

源码按 UTF-8 读取。一个标识符是**一段连续的非空白、非标点字符**，所以关键字、函数名、变量名都是这种“词”。词与词之间必须用空白或标点隔开：

```homo
i 便加 1 罢        // 正确
i便加 1 罢         // 错误：「i便加」会被当成一个标识符
```

唯一的连写例外是逻辑非：`迫真i` 等价于 `迫真 i`。

### 数字

只有十进制整数和带小数点的小数：

```homo
114514
3.14
-1            // 解析成 0 - 1
```

不支持 `1e5`、`0x10` 这类写法。

### 字符串

字符串可以用半角或全角引号包围，开闭引号不必同族：

```homo
"田所浩二"
“田所浩二”
'雪'
```

推荐统一用半角双引号。常见转义按 C++ 规则生效：`\"`、`\\`、`\n`、`\t`。在 `脱出` 的模板里额外支持 `\{`、`\}` 表示字面大括号。

**限制：字符串字面量不要跨行书写。** 词法层允许换行，但换行会被原样写进生成的 C++ 字符串字面量，导致编译失败。

### 标点

半角与全角的圆括号、逗号可以混用：

```homo
求和（1，2，3）噗叽啪
```

会被规范成 `求和(1, 2, 3)噗叽啪`。

### 注释与分号

```homo
// 单行注释
/* 多行
   注释 */
```

语句之间的分号是可选的，写不写都行。

## 程序结构

一个 homo 文件由以下几种顶层元素组成：

```homo
inm 库                 // 引入同目录的 库.homo

你是一个一个一个 全局变量 事 0 罢    // 全局变量定义

类 类名 {
    // 字段和方法
}

函数名(参数){
    // 函数体
}
```

- `inm 库` 引入另一个 `.homo` 文件，详见[多文件与 inm](#多文件与-inm)。
- `inm 类名 from 文件` 只引入指定类。
- 函数用完整定义，不再有单独的 `.inm` 声明文件。
- 顶层可以定义全局变量，语法与函数里的变量声明相同，详见[全局变量](#全局变量)。
- 顶层不能写赋值等普通语句，这类代码要放进函数或方法里。
- 主程序必须定义入口函数 `会员制餐厅`。

### 入口

入口函数必须是**主程序 `.homo`** 里定义的 `会员制餐厅`。主程序里没有它时会报“没有主函数入口”，不会选其他函数，也不会从被 `inm` 引用其他 `.homo` 借用入口。入口函数不能带参数。

```homo
会员制餐厅(){
    (0)人幸终
}
```

入口函数返回 0 表示正常结束，此时进程退出码为 2；返回非 0 的值时，该值就是进程退出码。

## 值与类型

homo 是动态类型的：变量不写类型标签，类型由当前值决定。

| 类型 | 字面量 / 来源 | 说明 |
| --- | --- | --- |
| 整数 | `1919810` | C++ `long long` |
| 浮点数 | `3.14` | C++ `double` |
| 字符串 | `"雪"` | UTF-8 文本 |
| 布尔 | `确信`（真）、`大嘘`（假），或比较/逻辑运算的结果 | 打印为 `1` / `0` |
| 虚无 | `虚无` | 空值，只与虚无相等 |
| 数组 | `[1, 2, 3]`、`你是一个一个一个 a [5] …` | 值语义 |
| 对象 | `新建 类名(...)` | 引用语义 |

`长度(值)` 对数组返回元素个数，对字符串返回**字符数**（按 UTF-8 字符计，不是字节数）。

```homo
脱出(长度("田所浩二"))噗叽啪   // 4
脱出(长度([1, 2, 3]))噗叽啪    // 3
```

对其它类型调用 `长度` 是运行错误：`只有数组和字符串有长度`。

### 打印形式

- 整数：`42`
- 浮点：`3.14`；整数值的浮点保留 `.0`，例如 `2.0`
- 布尔：`1` / `0`
- 虚无：`虚无`
- 字符串：原样输出；但出现在数组或对象内部时会带引号
- 数组：`[1, "雪", 虚无]`
- 对象：`类名 { 字段: 值, 字段: 值 }`

## 表达式与运算

### 算术

| 写法 | 含义 |
| --- | --- |
| `a + b` | 加法；只要有一边是字符串，就做字符串拼接 |
| `a - b` | 减法 |
| `a * b` | 乘法 |
| `a / b` | 除法；两边都是整数时向零截断 |
| `a 化粪 b` | 取模（C++ `%` / `fmod`） |

规则：

- 只要有一边是浮点数，结果就是浮点数；否则整数运算。
- `+` 只要有一边是字符串，就按 `as_string()` 拼成字符串：`"年龄：" + 24` 得到 `"年龄：24"`。
- 除数为 0 是运行错误：`除数不能为 0`。
- 字符串参与 `- * / 化粪` 时会用 `atoll` / `atof` 做**前缀解析**：`"12abc" - 1` 得到 `11`，`""` 得到 `0`。需要严格校验请用 `转数字`。
- **数组和对象不要参与算术**：它们会退化成默认标量（整数 0），结果容易出乎意料。

### 比较

语言只提供两种比较写法：

```homo
老爷你下面的(年龄 甚至 24)都白了{ ... }        // 小于
老爷你下面的((年龄)先辈(24)说)都白了{ ... }    // 等于
```

相等比较固定写成 `(a)先辈(b)说`：两个操作数各自用括号包起来，末尾的 `说` 不能省略。

其它比较用 `迫真`（逻辑非）组合出来：

| 想要 | 写法 |
| --- | --- |
| `a >= b` | `迫真(a 甚至 b)` |
| `a != b` | `迫真((a)先辈(b)说)` |
| `a > b` | `b 甚至 a` |
| `a <= b` | `迫真(b 甚至 a)` |

比较细节：

- 两边都是字符串时，按字典序比较，`(a)先辈(b)说` 比较内容。
- 其它标量按数值比较：`(确信)先辈(1)说`、`(大嘘)先辈(0)说` 都为真。
- 数组的相等比较是**深比较**（逐元素递归比较）；对象的相等比较是**引用比较**（同一个对象才相等）。
- 数组或对象用 `甚至` 比较大小是运行错误：`数组或对象不能比较大小`。

### 逻辑运算

```homo
a 且 b       // 逻辑与，短路
a 或 b       // 逻辑或，短路
迫真 a       // 逻辑非
迫真((a)先辈(b)说)
```

`且` / `或` 会短路，结果是布尔值。

### 真值

以下为假，其余为真：

- `虚无`
- 整数或浮点 `0`
- 空字符串 `""`
- 布尔假

注意：**数组和对象在条件里目前恒为假**，因为它们会被转成默认标量 0；而数组字面量直接写在条件里（例如 `老爷你下面的([1, 2])都白了`）甚至无法通过 C++ 编译。写条件时请显式比较，例如 `长度(数组) 甚至 0` 或 `(数组)先辈([])说`。

### 优先级

从低到高：

```
或
且
甚至
+ -
* / 化粪
一元 -、迫真
下标 []、取字段 .、调用 ()
```

`(a)先辈(b)说` 的两个操作数都自带括号，里面的表达式按上面的优先级完整求值，所以不需要为它单独记优先级。

拿不准时直接加括号。

## 变量与作用域

### 声明

```homo
你是一个一个一个 年龄 事 24 罢          // 带初值
你是一个一个一个 名字 哼哼哼啊啊啊啊啊    // 无初值定义，初值为 0（在 .homo 里）
你是一个一个一个 数组 [10] 哼哼哼啊啊啊啊啊
你是一个一个一个 数组 [10] 事 [1, 2] 罢
```

- `你是一个一个一个` 是声明头，`哼哼哼啊啊啊啊啊` 是无初值声明的结尾，`事 … 罢` 是带初值的声明。
- 声明时中括号里的长度只对数组有意义，见[数组](#数组)。
- 没有显式初值的变量初值是整数 0。

### 赋值

```homo
年龄 事 25 罢
年龄 便加 1 罢
年龄 便减 1 罢
年龄 便乘 2 罢
年龄 便除 2 罢
```

- 赋值只能用 `事`，写成 `=` 会报错。
- 复合赋值是 `便加` / `便减` / `便乘` / `便除`。
- 对**未声明的名字**赋值，等价于在当前块里声明它：`x 事 1 罢` 可以直接用。
- 变量的类型不固定，可以重新赋成别的标量类型；但已经确定的普通变量不能再被赋成数组字面量：
  ```homo
  你是一个一个一个 x 事 1 罢
  x 事 [1, 2] 罢      // 错误：「x」不是数组，不能用数组字面量赋值
  ```

### 块级作用域

每个 `{}` 块都会压入一层新作用域：

- 内层可以读取和修改外层变量。
- 内层用 `你是一个一个一个` 声明同名变量会**遮蔽**外层变量。
- 内层声明的变量在块结束时就消失。
- 同一个作用域里重复声明同名变量是编译错误。
- 使用未声明的变量是编译错误：`未定义的变量「x」`。

```homo
会员制餐厅(){
    你是一个一个一个 x 事 1 罢
    老爷你下面的(确信)都白了{
        你是一个一个一个 x 事 2 罢   // 遮蔽外层的 x
        脱出(x)噗叽啪                // 2
    }
    脱出(x)噗叽啪                    // 1
    (0)人幸终
}
```

### 全局变量

在顶层用同样的声明语法定义，整个程序都能访问：

```homo
你是一个一个一个 基数 事 10 罢
你是一个一个一个 名字 事 "雪" 罢
你是一个一个一个 表 [3] 事 [1, 2] 罢    // [1, 2, 0]

打招呼(问候 事 名字 + "！"){
    脱出(问候)噗叽啪
}

改基数(v){
    基数 事 v 罢
}

会员制餐厅(){
    脱出(基数)噗叽啪                  // 10
    改基数(7)噗叽啪
    脱出(基数)噗叽啪                  // 7
    你是一个一个一个 基数 事 99 罢    // 遮蔽全局
    脱出(基数)噗叽啪                  // 99
    打招呼()噗叽啪                    // 雪！
    (0)人幸终
}
```

- 所有函数、方法、字段初值和默认参数都能直接读取全局变量。
- 普通赋值会修改全局本身；局部声明同名变量则会遮蔽它，和块级遮蔽一致。
- 全局变量的初值在入口函数之前、按声明顺序求值；初值只能引用**前面**已声明的全局，引用后面的会报
  `全局变量「x」还没声明；全局初始值只能引用前面已声明的全局`。
- 全局变量不能和函数或类同名，同一个名字也不能声明两次。

`回数` 是保留名字，只能由 `回啊` 循环提供，不能声明或赋值。

语法关键字不能用作变量名、参数名或字段名，否则报 `「类」是关键字，不能用作变量名`。内置函数名（如 `长度`、`随机`、`脱出`）不在此列，仍可被同名变量遮蔽。

## 控制流

### 条件

```homo
老爷你下面的(条件)都白了{
    ...
}戳啦(另一个条件)嘛{
    ...
}戳啦极霸矛嘛{
    ...
}
```

`戳啦(条件)嘛` 可以出现多次，`戳啦极霸矛嘛` 是最后的分支。

### while

```homo
动起来啊动起来(i 甚至 10){
    脱出(i)噗叽啪
    i 便加 1 罢
}
```

### do-while

```homo
是栗老师让我{
    脱出("至少执行一次")噗叽啪
}动起来的(i 甚至 10)
```

### 计数循环

```homo
(n)回啊(m)回{
    // 循环体
}
```

两端的值是任意整数表达式，满足：

- `n == m`：循环 `n` 次，`回数` 从 0 数到 n-1。
- `n != m`：循环 `|n - m|` 次，`回数` 从 n 开始一步步走向 m（不包含 m）。`n > m` 时每次减 1，否则每次加 1。

```homo
(3)回啊(3)回{
    脱出(回数)噗叽啪        // 0 1 2
}
(1)回啊(4)回{
    脱出(回数)噗叽啪        // 1 2 3
}
(4)回啊(1)回{
    脱出(回数)噗叽啪        // 4 3 2
}
```

`回数` 只在循环体内可见；循环变量会自动推进，`速达哟` 也不会漏掉推进。

### 多分支

```homo
人类有三大欲望(值){
    食欲(1)
        脱出("一")噗叽啪
    食欲(2)
        脱出("二")噗叽啪
    性欲睡眠欲
        脱出("其它")噗叽啪
}
```

- 被比较的值只求值一次。
- 从上到下依次匹配，第一个匹配的分支执行，**没有贯穿**。
- `性欲睡眠欲` 可以写在任意位置，但只会在没有分支匹配时执行。
- `我已经等不及了` 可以提前跳出多分支。

### break / continue

```homo
我已经等不及了     // 跳出循环；在多分支里跳过剩余分支
速达哟             // 进入下一次循环
```

## 函数

### 定义与调用

```homo
求和(a, b){
    (a + b)人幸终
}

会员制餐厅(){
    脱出(求和(1, 2))噗叽啪
    (0)人幸终
}
```

- 函数定义只能写在顶层。
- 返回值写成 `(表达式)人幸终`；没有执行到返回语句时返回 0。
- 调用可以作为表达式，也可以单独成句，单独成句时以 `噗叽啪` 结尾。
- 支持递归，`quicksort.homo` 就是例子。

### 默认参数

```homo
打招呼(问候 事 "你好", 名字 事 "田所浩二"){
    脱出(问候 + "，" + 名字 + "！")噗叽啪
    (0)人幸终
}
```

- 默认值在**调用点**展开计算，所以每次调用都会重新求值。
- 带默认值的参数后面不能再出现必填参数。
- 省略的实参按顺序用默认值补齐。

### 可变参数

```homo
求和(一坨 数){
    你是一个一个一个 总 事 0 罢
    (长度(数))回啊(长度(数))回{
        总 便加 数[回数] 罢
    }
    (总)人幸终
}

脱出(求和(1, 2, 3, 4))噗叽啪    // 10
脱出(求和())噗叽啪             // 0
```

- `一坨 名字` 必须写在参数列表最后，而且只能写一次。
- 函数体内它就是普通数组，用 `长度` 和下标遍历。
- 它可以和默认参数同时使用，例如 `打招呼(问候 事 "你好", 一坨 名字)`。

### 参数个数检查

- 直接调用普通函数时，参数个数在编译期检查。
- 省略带默认值的参数是合法的。
- 用户函数不能和内置函数同名，否则报 `「X」是内置函数名，不能用作函数名`。
- 方法通过对象动态分发，参数个数在运行期检查。

## 类与对象

```homo
类 计数器 {
    你是一个一个一个 总数 事 0 罢

    首(初值){
        总数 事 初值 罢
    }

    加(n){
        总数 便加 n 罢
        (总数)人幸终
    }
}

会员制餐厅(){
    你是一个一个一个 计 事 新建 计数器(10) 罢
    脱出(计.加(5))噗叽啪     // 15
    (0)人幸终
}
```

### 规则

- 类体里只能写访问标记、字段声明（`你是一个一个一个 …`）和方法。
- 一个类至少要有一个方法。
- 方法里可以直接使用字段名，等价于访问当前对象；不需要也不存在 `this`。
- 参数可以遮蔽同名字段。
- `首` 是特殊的构造方法：写 `新建 类名(实参)` 时自动调用它。
- 一个类可以有多个 `首`，按实参个数选择；参数个数相同的两个 `首` 不能并存。
- 类没有 `首` 时，`新建 类名()` 不能带参数，否则是编译错误。
- 字段声明里可以写初值、数组长度，规则与普通变量相同。
- 对象的方法用 `对象.方法(实参)` 调用；字段用 `对象.字段` 读取，也可以直接赋值：`对象.字段 事 值 罢`。

### 成员可见性

类体默认公开，可以用两个访问标记切换后续字段和方法的可见性：

```homo
类 计数器 {
    摄影禁止
    你是一个一个一个 总数 事 0 罢
    偷偷加(n){
        总数 便加 n 罢
        (总数)人幸终
    }

    想看就看个够
    首(初值){
        总数 事 初值 罢
    }
    加(n){
        (偷偷加(n))人幸终
    }
}

会员制餐厅(){
    你是一个一个一个 计 事 新建 计数器(10) 罢
    脱出(计.加(5))噗叽啪     // 15
    脱出(计.总数)噗叽啪      // 运行错误：私有字段
    (0)人幸终
}
```

- `摄影禁止` 让后面的成员私有，`想看就看个够` 恢复公开；可以切换多次。
- 私有成员只能在本类方法里用裸名字访问。写成 `对象.字段` 或 `对象.方法()` 一律是运行错误：
  `「计数器.总数」是私有字段，不能在类外访问`。
- `首` 即使被标为私有，`新建 类名(实参)` 仍会调用它。

### 值语义 vs 引用语义

- **数组是值语义**：赋值、传参都会复制整个数组。
- **对象是引用语义**：赋值只是复制引用，两个变量指向同一个对象。

```homo
你是一个一个一个 a 事 新建 计数器(0) 罢
你是一个一个一个 b 事 a 罢
b.加(1)噗叽啪
脱出(a.总数)噗叽啪     // 1：a 和 b 是同一个对象
```

### 动态访问

字段和方法是否存在在运行期检查：

```homo
脱出(计.不存在)噗叽啪      // 运行错误：对象没有字段「不存在」
脱出(计.不存在())噗叽啪    // 运行错误：对象没有方法「不存在」
```

## 数组

### 声明

```homo
你是一个一个一个 数字 [5] 哼哼哼啊啊啊啊啊    // 5 个 0
你是一个一个一个 字母 [3] 事 ["a", "b"] 罢  // 补齐成 ["a", "b", 0]
你是一个一个一个 列表 事 [1, 2, 3] 罢       // 按字面量长度建数组
你是一个一个一个 空 事 [] 罢
```

声明里的长度会把初值“整理”成指定长度：不足补 0，多出的截掉。

多维数组写多个中括号，并按层整理：

```homo
你是一个一个一个 棋盘 [2][3] 哼哼哼啊啊啊啊啊
你是一个一个一个 棋盘 [2][3] 事 [[1, 2], [3]] 罢
// 结果是 [[1, 2, 0], [3, 0, 0]]
```

### 下标与赋值

```homo
脱出(数字[0])噗叽啪
数字[0] 事 42 罢
数字[1] 便加 1 罢
棋盘[1][2] 事 9 罢
```

- 下标从 0 开始，负数或越界是运行错误：
  `数组下标越界：下标 5，长度 3`
- 下标值会先按整数处理。
- 数组是值类型：`b 事 a 罢` 之后修改 `b` 不会影响 `a`。

## 字符串

### 基本操作

```homo
你是一个一个一个 名 事 "田所浩二" 罢
脱出(名[0])噗叽啪          // 田
脱出(长度(名))噗叽啪       // 4
脱出("你好，" + 名)噗叽啪
```

- 下标按 UTF-8 **字符**计数，不是字节。
- 字符串不能按下标赋值：`名[0] 事 "x" 罢` 会报运行错误 `字符串不能按下标赋值`。
- 字符串是值类型。

### 字符串内置函数

所有函数都按 UTF-8 字符处理。除 `连接` 外，字符串参数必须是真字符串，不做隐式转换。

| 函数 | 参数 | 返回 | 说明 |
| --- | --- | --- | --- |
| `取子串(串, 起)` | 字符串, 整数 | 字符串 | 从字符下标 `起` 截到末尾 |
| `取子串(串, 起, 长)` | 字符串, 整数, 整数 | 字符串 | 截取 `长` 个字符 |
| `查找(串, 子)` | 字符串, 字符串 | 整数 | 首次出现的字符下标；找不到为 -1；空子串为 0 |
| `包含(串, 子)` | 字符串, 字符串 | 布尔 | 是否包含子串 |
| `替换(串, 旧, 新)` | 字符串, 字符串, 字符串 | 字符串 | 替换所有出现 |
| `分割(串, 分隔符)` | 字符串, 字符串 | 数组 | 按分隔符切分，保留空段 |
| `连接(数组, 分隔符)` | 数组, 标量 | 字符串 | 用分隔符把标量元素拼成字符串 |
| `去空白(串)` | 字符串 | 字符串 | 去掉两端 ASCII 空白 |
| `转数字(串)` | 字符串 | 整数 / 浮点 | 严格解析数字 |
| `转大写(串)` / `转小写(串)` | 字符串 | 字符串 | 只转换 ASCII 字母 |

示例：

```homo
脱出(取子串("田所浩二", 1))噗叽啪        // 所浩二
脱出(取子串("田所浩二", 1, 2))噗叽啪     // 所浩
脱出(查找("田所浩二", "浩"))噗叽啪       // 2
脱出(查找("田所浩二", "雪"))噗叽啪       // -1
脱出(包含("田所浩二", "浩"))噗叽啪       // 1
脱出(替换("雪雪雪", "雪", "雪（悲）"))噗叽啪
脱出(分割("a,,b", ","))噗叽啪            // ["a", "", "b"]
脱出(连接(["a", 1, 虚无], "-"))噗叽啪    // a-1-虚无
脱出(去空白("  雪  "))噗叽啪             // 雪
脱出(转数字(" 42 "))噗叽啪               // 42
脱出(转数字("3.14"))噗叽啪               // 3.14
脱出(转大写("abcXYZ"))噗叽啪             // ABCXYZ
脱出(转小写("abcXYZ"))噗叽啪             // abcxyz
```

细节与错误：

- `取子串` 的起点可以等于长度（得到空串）；起点越界、长度为负、起点加长度越界都会报
  `取子串越界：起点 X，长度 Y，总长 Z`。
- `替换` 的旧串不能为空；替换后从新串末尾继续，`替换("aa", "a", "aa")` 不会死循环。
- `分割` 的分隔符不能为空；开头和结尾的空段会保留。
- `连接` 的第一个参数必须是数组，分隔符和每个元素都必须是标量；`虚无` 会拼成文本 `虚无`。
- `转数字` 会先去掉两端 ASCII 空白，并要求整个字符串都是合法数字；`"12abc"`、`"1e"`、`""` 都会报
  `不是合法的数字：「…」`。
- `转大写` / `转小写` / `去空白` 只处理 ASCII，中文不受影响。
- 参数个数错误在编译期报，例如 `取子串 需要 2 到 3 个参数，但给了 4 个`。

## 输入与输出

### 脱出

`脱出` 只接受一个参数，只能作为独立语句，并以 `噗叽啪` 结尾；输出后自动换行。

```homo
脱出("年龄：{年龄}")噗叽啪
脱出(某个值)噗叽啪
脱出("{a} + {b} = {a + b}")噗叽啪
```

- 当参数是**字符串字面量**时，`{表达式}` 会被当作模板：先计算表达式，再把结果拼进文本。
- 模板里的表达式可以调用函数、取下标、取字段等。
- 模板里不能嵌套另一层带引号的字符串字面量；需要时先存进变量。
- 参数不是字符串字面量时（例如变量、数组、数字），整体按打印规则输出，不做模板替换。
- 数组和对象会按结构展开打印。

### 读入

```homo
你是一个一个一个 n 事 读入() 罢
```

读取一个整数（底层是 `scanf("%lld")`），会跳过前面的空白。读到非数字或 EOF 时返回 0。

### 读行

```homo
你是一个一个一个 行 事 读行() 罢
```

跳过行首的空格、制表符、回车和换行，读取到行尾，并去掉末尾的 `\r`。EOF 时返回空串。因为行首空白会被跳过，不能用来保留缩进。

在桌面编辑器里运行时，输出面板下方的「标准输入」条可以把每一行实时送给正在运行的程序。

## 编译工具链

`homo.py` 的处理流程：

```
词法分析 → 语法分析 → 名字与作用域检查 → 类型推导 → 生成 C++
```

生成 C++ 前，`homo.py` 会递归解析 `inm`，把主文件和所有被引用的 `.homo` 合并成一个程序，并记录每个模块在合并后程序里的行号范围。

生成 C++ 后：

- 按 `HOMO_CXX` 环境变量、`g++`、`clang++`、`c++`、`clang-cl`、`cl` 的顺序查找编译器；Windows 上还会用 `vswhere` 自动查找 Visual Studio 的 MSVC 和 `vcvars64.bat`。
- MinGW / clang 使用 `-std=c++17 -O0`；MSVC 使用 `/std:c++17 /EHsc /O2 /utf-8`。Windows 上会显式使用 UTF-8 源码/执行字符集，中文标识符和字符串不会乱码。
- 临时构建目录会写入 `main.cpp` 和 `homo_runtime.hpp`。
- 生成的 C++ 里带一张源码位置表，运行期错误会打印「文件 + 文件内行号」，多文件时也能指对 `.homo`。
- `--keep` 可以保留目录，便于查看生成的 C++。

## 桌面编辑器

`homo_editor.py` 是一个纯 Tk 的桌面程序，不需要浏览器、不需要启动本地 HTTP 服务，Windows 和 macOS 使用同一套代码。

```bash
python3 homo_editor.py                      # 空白编辑器 + 示例代码
python3 homo_editor.py .                    # 打开当前项目文件夹
python3 homo_editor.py main.homo            # 打开单个主程序
```

界面：

- **左侧项目树**：显示项目里的 `.homo`，双击打开；右键可以设为主程序、新建文件、在文件管理器中显示。主程序显示为屎黄色。
- **多标签编辑区**：每个文件一个标签，标签右侧的 `×` 可以直接关闭文件；支持撤销/重做、行号、自动补全、查找替换、转到行、注释切换、字体缩放；标签上右键也可以保存或关闭。
- **输入辅助**：输入 `(`、`[`、`{`、`（`、引号时自动补全右半边；输入已有右括号时自动跳过；退格/删除一次删掉成对符号。输入标识符时自动弹出补全列表，`Ctrl+Space` / `⌘J` 也可以手动打开。
- **实时检查**：停止输入约半秒后自动做词法/语法/inm/名字检查；错误行号变红、代码行加下划线，编辑器顶部显示错误信息，点击可直接跳到出错位置。编译错误也会同步显示在这里。
- **字体大小**：根据屏幕分辨率自动缩放；低分屏不会再使用固定 13pt，`⌘/Ctrl+=`、`⌘/Ctrl+-` 仍可手动调整代码字号。
- **语法高亮**：沿用旧网页版配色——声明红色、关键字/函数紫色、类名青绿、参数橙色、布尔/虚无深蓝、字符串淡蓝、注释灰色，花括号按嵌套深度循环黄/紫/蓝。
- **工具栏**：打开文件夹、打开文件、保存、运行、停止、编译检查、清空输出；右侧显示当前主程序。
- **下方输出区**：
  - **运行结果**：实时显示程序输出，标准错误标红。
  - **问题**：编译错误 / C++ 错误列表，双击（或回车）跳到对应文件和行。
  - **生成的 C++**：查看当前程序翻译出的 C++17。
- **标准输入条**：程序运行时可以逐行发送输入，适合 `读入` / `读行`。
- **文件对话框**：macOS 使用系统原生文件/文件夹面板（拖动流畅、文件夹选择正确，但按钮文字由 macOS/Tk 固定为英文）；Windows 使用系统原生对话框。

- 「打开文件夹」会把文件夹作为项目根目录，并在有 `main.homo` / `会员制餐厅.homo` 时自动选为主程序。

- **运行 / 编译检查 / 导出始终使用当前设置的主程序**，与现在编辑的是哪个文件无关。比如正在编辑另一个 `helper.homo`，点运行仍从 `main.homo` 开始。
- 主程序显示在工具栏右侧；要换入口，右键另一个 `.homo` →「设为主程序」。
- 运行入口只从主程序 `.homo` 的 `会员制餐厅` 开始；没有就报“没有主函数入口”。
- 「文件 → 新建项目」会创建一个 `main.homo` + `问候.homo` 的最小多文件项目。
- 点运行时会先自动保存已有文件名的修改；没有主程序时直接运行当前 `.homo` 或未命名缓冲区。
- 编译错误提示使用 `文件:行: 信息`；运行错误使用 `运行错误（文件 第 N 行）：信息`。

## 打包成桌面程序

两个脚本都会自动创建 `.build-venv`、安装 PyInstaller，并把 `homo_runtime.hpp` 一起打进包里。

### macOS

```bash
./build_macos.sh
open dist/HomoEditor.app
```

生成 `dist/HomoEditor.app`。第一次打开若被 Gatekeeper 拦截，右键 →「打开」。脚本生成的是当前 Mac 架构（Apple Silicon / Intel）对应的包；要分发给其它架构需要在该架构上重新打包，或使用 universal2 Python。

### Windows

```bat
build_windows.bat
dist\HomoEditor.exe
```

生成单文件 `dist\HomoEditor.exe`。脚本会创建 `.build-venv`、安装 PyInstaller，并把完整日志写到 `build\windows-build.log`；失败时窗口会停住并显示日志路径，不会一闪而过。

默认依次查找 `py -3` 和 `python`。也可以指定 Python 可执行文件的完整路径：

```bat
set "PYTHON=C:\Users\你\AppData\Local\Programs\Python\Python312\python.exe"
build_windows.bat
```

如果提示没有 Tkinter，请安装 python.org 的 Python，而不是缺少 Tk 的精简版。Windows 首次运行可能被 SmartScreen 拦截，选择「更多信息 → 仍要运行」；正式分发请自行签名。

打包后的程序仍然调用系统里的 C++ 编译器：目标机器需要安装 MinGW-w64（`g++`）或 Visual Studio Build Tools。编译器不会被打进 `.exe` / `.app` 里。

## 错误与退出码

| 情况 | 输出 | 退出码 |
| --- | --- | --- |
| 成功 | — | 2 |
| 编译错误（源文件） | `编译错误：main.homo:12: …` | 114 |
| 编译错误（标准输入） | `编译错误：第 N 行：…` | 114 |
| 运行错误 | `运行错误（库.homo 第 12 行）：…` | 51 |
| `--run` 下 C++ 编译失败 | 编译器输出 | 51 |
| `-o` 下 C++ 编译失败 | 编译器输出 | 1 |
| 程序自行返回非 0 | — | 程序的返回值 |

运行错误使用 51 而不是 514：POSIX 进程退出码只有 8 位，514 会被截断成 2，与表示成功的 2 冲突。

编译错误在生成 C++ 之前就能发现：词法、语法、inm 解析、未定义变量/函数、参数个数、类与构造函数、保留名等。

运行错误包括：下标越界、除零、类型不符、非法数字、访问不存在的字段/方法、访问私有成员、数组比较大小等。

## 已知限制

- 字符串字面量不能跨行。
- 数组和对象变量在条件、`且`、`或` 里恒为假；数组字面量直接用作条件会编译失败。请显式比较。
- 数组和对象参与算术会退化成 0，结果没有意义。
- 比较只有 `甚至` 和 `(a)先辈(b)说`，其余用 `迫真` 组合。
- 没有继承、接口、异常；`inm` 直接合并 `.homo` 定义，支持整文件导入和 `inm 类名 from 文件` 的选择性类导入；没有包管理器或条件导入。
- 不再支持 `.inm` 扩展名；同一个 `.homo` 只加载一次。
- 不允许循环 `inm`；`inm` 的路径相对当前文件；跨项目路径请用引号写明确的相对/绝对路径，或用 `-I` 指定搜索目录。
- `读行` 会跳掉行首空白。
- `--run` 在非交互环境下不转发标准输入。
- 方法参数个数在运行期检查。
- 数字字面量只支持十进制整数和小数，不支持指数、十六进制。

## 完整示例

下面这个程序覆盖了类、构造函数、可变参数、区间循环、分割、连接、字符串下标和模板输出，可以用 `python3 homo.py 示例.homo --run` 直接运行：

```homo
类 计数器 {
    你是一个一个一个 总数 事 0 罢

    首(初值){
        总数 事 初值 罢
    }

    加(n){
        总数 便加 n 罢
        (总数)人幸终
    }
}

求和(一坨 数){
    你是一个一个一个 总 事 0 罢
    (长度(数))回啊(长度(数))回{
        总 便加 数[回数] 罢
    }
    (总)人幸终
}

会员制餐厅(){
    你是一个一个一个 计 事 新建 计数器(10) 罢
    脱出("加 5 次后：{计.加(5)}")噗叽啪

    你是一个一个一个 词 事 分割("苹果，香蕉，雪", "，") 罢
    (长度(词))回啊(长度(词))回{
        脱出("{回数}：{词[回数]}")噗叽啪
    }
    脱出(连接(词, " / "))噗叽啪

    你是一个一个一个 字 事 "田所浩二" 罢
    脱出("首字：{字[0]}")噗叽啪
    脱出(求和(1, 2, 3, 4))噗叽啪
    (0)人幸终
}
```

输出：

```
加 5 次后：15
0：苹果
1：香蕉
2：雪
苹果 / 香蕉 / 雪
首字：田
10
```
