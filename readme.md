# homo 语言手册

homo 是一门用inm梗作关键字的小型编程语言。它不直接解释执行，而是先翻译成 C++17，再交给系统里的 C++ 编译器（`g++` / `clang++` / `c++`）编译成原生可执行文件。

- 工具链：`homo.py`（词法、语法、名字检查、类型推导、C++ 代码生成、命令行入口）
- 运行时：`homo_runtime.hpp`（值类型、运算、内置函数、输出）
- Web 编辑器：`app.py` + `index.html`

它带有一点玩笑性质，但语言本身是完整的：动态类型、块级作用域、数组、字符串函数、函数默认参数与可变参数、类与对象、递归、四种循环、多分支。仓库里的 `quicksort.homo`、`variadic.homo`、`minesweeper.homo` 都是可以直接运行的真实程序。

## 快速开始

需要 Python 3 和一个支持 C++17 的编译器。

最小的程序：

```homo
会员制餐厅(){
    脱出("哼哼哼啊啊啊啊啊")噗叽啪
    (0)人幸终
}
```

保存为 `hello.homo`，然后：

```bash
python3 homo.py hello.homo --run
```

输出：

```
哼哼哼啊啊啊啊啊
```

也可以把翻译结果直接打印出来：

```bash
python3 homo.py hello.homo > hello.cpp
```

### 命令行参数

```
python3 homo.py [源文件] [-o 输出路径] [--run] [--keep]
```

| 参数 | 作用 |
| --- | --- |
| 不写源文件 | 从标准输入读源码，向标准输出打印 C++ |
| `-o PATH` | 编译并把可执行文件复制到 `PATH` |
| `--run` | 编译后立即运行 |
| `--keep` | 保留临时构建目录，并打印它的路径 |

注意 `--run` 的输入行为：只有当标准输入是终端时，程序才会继承终端、可以交互输入。用管道或重定向喂输入时（例如 `echo 1 | python3 homo.py x.homo --run`），子进程的标准输入会被立刻关闭，`读入` 读到 EOF、`读行` 读到空串。需要脚本化输入时，先 `-o` 生成可执行文件再单独运行它：

```bash
python3 homo.py minesweeper.homo -o /tmp/ms
/tmp/ms
```

## 词法规则

### 标识符与关键字

源码按 UTF-8 读取。一个标识符是**一段连续的非空白、非标点字符**，所以关键字、函数名、变量名都是这种“词”。词与词之间必须用空白或标点隔开：

```homo
i 便加 1 罢        // 正确
i便加 1 罢         // 错误：「i便加」会被当成一个标识符
```

唯一的连写例外是逻辑非：`迫真i` 等价于 `迫真 i`。

### 数字

只有十进制整数和带小数点的小数：

```homo
114514
3.14
-1            // 解析成 0 - 1
```

不支持 `1e5`、`0x10` 这类写法。

### 字符串

字符串可以用半角或全角引号包围，开闭引号不必同族：

```homo
"田所浩二"
“田所浩二”
'雪'
```

推荐统一用半角双引号。常见转义按 C++ 规则生效：`\"`、`\\`、`\n`、`\t`。在 `脱出` 的模板里额外支持 `\{`、`\}` 表示字面大括号。

**限制：字符串字面量不要跨行书写。** 词法层允许换行，但换行会被原样写进生成的 C++ 字符串字面量，导致编译失败。

### 标点

半角与全角的圆括号、逗号可以混用：

```homo
求和（1，2，3）噗叽啪
```

会被规范成 `求和(1, 2, 3)噗叽啪`。

### 注释与分号

```homo
// 单行注释
/* 多行
   注释 */
```

语句之间的分号是可选的，写不写都行。

## 程序结构

一个 homo 文件由三部分组成，且只能写在这三种顶层元素里：

```homo
import homocore        // 允许写，但当前没有任何作用

类 类名 {
    // 字段和方法
}

函数名(参数){
    // 函数体
}
```

- `import` 只为兼容旧写法而接受，不加载任何东西。
- 顶层不能写语句；所有代码都要放进函数或方法里。
- 程序至少要有一个函数。

### 入口

入口函数优先选 `会员制餐厅`；没有它时，选文件里的第一个函数。入口函数不能带参数。

```homo
会员制餐厅(){
    (0)人幸终
}
```

返回值会作为进程退出码，所以 `(0)人幸终` 表示正常结束。

## 值与类型

homo 是动态类型的：变量不写类型标签，类型由当前值决定。

| 类型 | 字面量 / 来源 | 说明 |
| --- | --- | --- |
| 整数 | `1919810` | C++ `long long` |
| 浮点数 | `3.14` | C++ `double` |
| 字符串 | `"雪"` | UTF-8 文本 |
| 布尔 | `确信`（真）、`大嘘`（假），或比较/逻辑运算的结果 | 打印为 `1` / `0` |
| 虚无 | `虚无` | 空值，只与虚无相等 |
| 数组 | `[1, 2, 3]`、`你是一个一个一个 a [5] …` | 值语义 |
| 对象 | `新建 类名(...)` | 引用语义 |

`长度(值)` 对数组返回元素个数，对字符串返回**字符数**（按 UTF-8 字符计，不是字节数）。

```homo
脱出(长度("田所浩二"))噗叽啪   // 4
脱出(长度([1, 2, 3]))噗叽啪    // 3
```

对其它类型调用 `长度` 是运行错误：`只有数组和字符串有长度`。

### 打印形式

- 整数：`42`
- 浮点：`3.14`；整数值的浮点保留 `.0`，例如 `2.0`
- 布尔：`1` / `0`
- 虚无：`虚无`
- 字符串：原样输出；但出现在数组或对象内部时会带引号
- 数组：`[1, "雪", 虚无]`
- 对象：`类名 { 字段: 值, 字段: 值 }`

## 表达式与运算

### 算术

| 写法 | 含义 |
| --- | --- |
| `a + b` | 加法；只要有一边是字符串，就做字符串拼接 |
| `a - b` | 减法 |
| `a * b` | 乘法 |
| `a / b` | 除法；两边都是整数时向零截断 |
| `a 化粪 b` | 取模（C++ `%` / `fmod`） |

规则：

- 只要有一边是浮点数，结果就是浮点数；否则整数运算。
- `+` 只要有一边是字符串，就按 `as_string()` 拼成字符串：`"年龄：" + 24` 得到 `"年龄：24"`。
- 除数为 0 是运行错误：`除数不能为 0`。
- 字符串参与 `- * / 化粪` 时会用 `atoll` / `atof` 做**前缀解析**：`"12abc" - 1` 得到 `11`，`""` 得到 `0`。需要严格校验请用 `转数字`。
- **数组和对象不要参与算术**：它们会退化成默认标量（整数 0），结果容易出乎意料。

### 比较

语言只提供两个比较算子：

```homo
老爷你下面的(年龄 甚至 24)都白了{ ... }   // 小于
老爷你下面的(年龄 就事 24)都白了{ ... }   // 等于
```

其它比较用 `迫真`（逻辑非）组合出来：

| 想要 | 写法 |
| --- | --- |
| `a >= b` | `迫真(a 甚至 b)` |
| `a != b` | `迫真(a 就事 b)` |
| `a > b` | `b 甚至 a` |
| `a <= b` | `迫真(b 甚至 a)` |

比较细节：

- 两边都是字符串时，按字典序比较，`就事` 比较内容。
- 其它标量按数值比较：`确信 就事 1`、`大嘘 就事 0` 都为真。
- 数组的 `就事` 是**深比较**（逐元素递归比较）；对象的 `就事` 是**引用比较**（同一个对象才相等）。
- 数组或对象用 `甚至` 比较大小是运行错误：`数组或对象不能比较大小`。

### 逻辑运算

```homo
a 且 b       // 逻辑与，短路
a 或 b       // 逻辑或，短路
迫真 a       // 逻辑非
迫真(a 就事 b)
```

`且` / `或` 会短路，结果是布尔值。写成 `与`、`完全一致`、`和` 会得到专门的提示，让你改用 `就事`、`且`。

### 真值

以下为假，其余为真：

- `虚无`
- 整数或浮点 `0`
- 空字符串 `""`
- 布尔假

注意：**数组和对象在条件里目前恒为假**，因为它们会被转成默认标量 0；而数组字面量直接写在条件里（例如 `老爷你下面的([1, 2])都白了`）甚至无法通过 C++ 编译。写条件时请显式比较，例如 `长度(数组) 甚至 0` 或 `数组 就事 []`。

### 优先级

从低到高：

```
或
且
甚至 / 就事
+ -
* / 化粪
一元 -、迫真
下标 []、取字段 .、调用 ()
```

拿不准时直接加括号。

## 变量与作用域

### 声明

```homo
你是一个一个一个 年龄 事 24 罢          // 带初值
你是一个一个一个 名字 哼哼哼啊啊啊啊啊    // 只有声明，初值为 0
你是一个一个一个 数组 [10] 哼哼哼啊啊啊啊啊
你是一个一个一个 数组 [10] 事 [1, 2] 罢
```

- `你是一个一个一个` 是声明头，`哼哼哼啊啊啊啊啊` 是无初值声明的结尾，`事 … 罢` 是带初值的声明。
- 声明时中括号里的长度只对数组有意义，见[数组](#数组)。
- 没有显式初值的变量初值是整数 0。

### 赋值

```homo
年龄 事 25 罢
年龄 便加 1 罢
年龄 便减 1 罢
年龄 便乘 2 罢
年龄 便除 2 罢
```

- 赋值只能用 `事`，写成 `=` 会报错。
- 复合赋值是 `便加` / `便减` / `便乘` / `便除`。
- 对**未声明的名字**赋值，等价于在当前块里声明它：`x 事 1 罢` 可以直接用。
- 变量的类型不固定，可以重新赋成别的标量类型；但已经确定的普通变量不能再被赋成数组字面量：
  ```homo
  你是一个一个一个 x 事 1 罢
  x 事 [1, 2] 罢      // 错误：「x」不是数组，不能用数组字面量赋值
  ```

### 块级作用域

每个 `{}` 块都会压入一层新作用域：

- 内层可以读取和修改外层变量。
- 内层用 `你是一个一个一个` 声明同名变量会**遮蔽**外层变量。
- 内层声明的变量在块结束时就消失。
- 同一个作用域里重复声明同名变量是编译错误。
- 使用未声明的变量是编译错误：`未定义的变量「x」`。

```homo
会员制餐厅(){
    你是一个一个一个 x 事 1 罢
    老爷你下面的(确信)都白了{
        你是一个一个一个 x 事 2 罢   // 遮蔽外层的 x
        脱出(x)噗叽啪                // 2
    }
    脱出(x)噗叽啪                    // 1
    (0)人幸终
}
```

`回数` 是保留名字，只能由 `回啊` 循环提供，不能声明或赋值。

语法关键字不能用作变量名、参数名或字段名，否则报 `「类」是关键字，不能用作变量名`。内置函数名（如 `长度`、`随机`、`脱出`）不在此列，仍可被同名变量遮蔽。

## 控制流

### 条件

```homo
老爷你下面的(条件)都白了{
    ...
}戳啦(另一个条件)嘛{
    ...
}戳啦极霸矛嘛{
    ...
}
```

`戳啦(条件)嘛` 可以出现多次，`戳啦极霸矛嘛` 是最后的分支。

### while

```homo
动起来啊动起来(i 甚至 10){
    脱出(i)噗叽啪
    i 便加 1 罢
}
```

### do-while

```homo
是栗老师让我{
    脱出("至少执行一次")噗叽啪
}动起来的(i 甚至 10)
```

### 计数循环

```homo
(n)回啊(m)回{
    // 循环体
}
```

两端的值是任意整数表达式，满足：

- `n == m`：循环 `n` 次，`回数` 从 0 数到 n-1。
- `n != m`：循环 `|n - m|` 次，`回数` 从 n 开始一步步走向 m（不包含 m）。`n > m` 时每次减 1，否则每次加 1。

```homo
(3)回啊(3)回{
    脱出(回数)噗叽啪        // 0 1 2
}
(1)回啊(4)回{
    脱出(回数)噗叽啪        // 1 2 3
}
(4)回啊(1)回{
    脱出(回数)噗叽啪        // 4 3 2
}
```

`回数` 只在循环体内可见；循环变量会自动推进，`速达哟` 也不会漏掉推进。

### 多分支

```homo
人类有三大欲望(值){
    食欲(1)
        脱出("一")噗叽啪
    食欲(2)
        脱出("二")噗叽啪
    性欲睡眠欲
        脱出("其它")噗叽啪
}
```

- 被比较的值只求值一次。
- 从上到下依次匹配，第一个匹配的分支执行，**没有贯穿**。
- `性欲睡眠欲` 可以写在任意位置，但只会在没有分支匹配时执行。
- `我已经等不及了` 可以提前跳出多分支。

### break / continue

```homo
我已经等不及了     // 跳出循环；在多分支里跳过剩余分支
速达哟             // 进入下一次循环
```

## 函数

### 定义与调用

```homo
求和(a, b){
    (a + b)人幸终
}

会员制餐厅(){
    脱出(求和(1, 2))噗叽啪
    (0)人幸终
}
```

- 函数定义只能写在顶层。
- 返回值写成 `(表达式)人幸终`；没有执行到返回语句时返回 0。
- 调用可以作为表达式，也可以单独成句，单独成句时以 `噗叽啪` 结尾。
- 支持递归，`quicksort.homo` 就是例子。

### 默认参数

```homo
打招呼(问候 事 "你好", 名字 事 "田所浩二"){
    脱出(问候 + "，" + 名字 + "！")噗叽啪
    (0)人幸终
}
```

- 默认值在**调用点**展开计算，所以每次调用都会重新求值。
- 带默认值的参数后面不能再出现必填参数。
- 省略的实参按顺序用默认值补齐。

### 可变参数

```homo
求和(一坨 数){
    你是一个一个一个 总 事 0 罢
    (长度(数))回啊(长度(数))回{
        总 便加 数[回数] 罢
    }
    (总)人幸终
}

脱出(求和(1, 2, 3, 4))噗叽啪    // 10
脱出(求和())噗叽啪             // 0
```

- `一坨 名字` 必须写在参数列表最后，而且只能写一次。
- 函数体内它就是普通数组，用 `长度` 和下标遍历。
- 它可以和默认参数同时使用，例如 `打招呼(问候 事 "你好", 一坨 名字)`。

### 参数个数检查

- 直接调用普通函数时，参数个数在编译期检查。
- 省略带默认值的参数是合法的。
- 用户函数不能和内置函数同名，否则报 `「X」是内置函数名，不能用作函数名`。
- 方法通过对象动态分发，参数个数在运行期检查。

## 类与对象

```homo
类 计数器 {
    你是一个一个一个 总数 事 0 罢

    首(初值){
        总数 事 初值 罢
    }

    加(n){
        总数 便加 n 罢
        (总数)人幸终
    }
}

会员制餐厅(){
    你是一个一个一个 计 事 新建 计数器(10) 罢
    脱出(计.加(5))噗叽啪     // 15
    (0)人幸终
}
```

### 规则

- 类体里只能写字段声明（`你是一个一个一个 …`）和方法。
- 一个类至少要有一个方法。
- 方法里可以直接使用字段名，等价于访问当前对象；不需要也不存在 `this`。
- 参数可以遮蔽同名字段。
- `首` 是特殊的构造方法：写 `新建 类名(实参)` 时自动调用它。
- 类没有 `首` 时，`新建 类名()` 不能带参数，否则是编译错误。
- 字段声明里可以写初值、数组长度，规则与普通变量相同。
- 对象的方法用 `对象.方法(实参)` 调用；字段用 `对象.字段` 读取，也可以直接赋值：`对象.字段 事 值 罢`。

### 值语义 vs 引用语义

- **数组是值语义**：赋值、传参都会复制整个数组。
- **对象是引用语义**：赋值只是复制引用，两个变量指向同一个对象。

```homo
你是一个一个一个 a 事 新建 计数器(0) 罢
你是一个一个一个 b 事 a 罢
b.加(1)噗叽啪
脱出(a.总数)噗叽啪     // 1：a 和 b 是同一个对象
```

### 动态访问

字段和方法是否存在在运行期检查：

```homo
脱出(计.不存在)噗叽啪      // 运行错误：对象没有字段「不存在」
脱出(计.不存在())噗叽啪    // 运行错误：对象没有方法「不存在」
```

## 数组

### 声明

```homo
你是一个一个一个 数字 [5] 哼哼哼啊啊啊啊啊    // 5 个 0
你是一个一个一个 字母 [3] 事 ["a", "b"] 罢  // 补齐成 ["a", "b", 0]
你是一个一个一个 列表 事 [1, 2, 3] 罢       // 按字面量长度建数组
你是一个一个一个 空 事 [] 罢
```

声明里的长度会把初值“整理”成指定长度：不足补 0，多出的截掉。

多维数组写多个中括号，并按层整理：

```homo
你是一个一个一个 棋盘 [2][3] 哼哼哼啊啊啊啊啊
你是一个一个一个 棋盘 [2][3] 事 [[1, 2], [3]] 罢
// 结果是 [[1, 2, 0], [3, 0, 0]]
```

### 下标与赋值

```homo
脱出(数字[0])噗叽啪
数字[0] 事 42 罢
数字[1] 便加 1 罢
棋盘[1][2] 事 9 罢
```

- 下标从 0 开始，负数或越界是运行错误：
  `数组下标越界：下标 5，长度 3`
- 下标值会先按整数处理。
- 数组是值类型：`b 事 a 罢` 之后修改 `b` 不会影响 `a`。

## 字符串

### 基本操作

```homo
你是一个一个一个 名 事 "田所浩二" 罢
脱出(名[0])噗叽啪          // 田
脱出(长度(名))噗叽啪       // 4
脱出("你好，" + 名)噗叽啪
```

- 下标按 UTF-8 **字符**计数，不是字节。
- 字符串不能按下标赋值：`名[0] 事 "x" 罢` 会报运行错误 `字符串不能按下标赋值`。
- 字符串是值类型。

### 字符串内置函数

所有函数都按 UTF-8 字符处理。除 `连接` 外，字符串参数必须是真字符串，不做隐式转换。

| 函数 | 参数 | 返回 | 说明 |
| --- | --- | --- | --- |
| `取子串(串, 起)` | 字符串, 整数 | 字符串 | 从字符下标 `起` 截到末尾 |
| `取子串(串, 起, 长)` | 字符串, 整数, 整数 | 字符串 | 截取 `长` 个字符 |
| `查找(串, 子)` | 字符串, 字符串 | 整数 | 首次出现的字符下标；找不到为 -1；空子串为 0 |
| `包含(串, 子)` | 字符串, 字符串 | 布尔 | 是否包含子串 |
| `替换(串, 旧, 新)` | 字符串, 字符串, 字符串 | 字符串 | 替换所有出现 |
| `分割(串, 分隔符)` | 字符串, 字符串 | 数组 | 按分隔符切分，保留空段 |
| `连接(数组, 分隔符)` | 数组, 标量 | 字符串 | 用分隔符把标量元素拼成字符串 |
| `去空白(串)` | 字符串 | 字符串 | 去掉两端 ASCII 空白 |
| `转数字(串)` | 字符串 | 整数 / 浮点 | 严格解析数字 |
| `转大写(串)` / `转小写(串)` | 字符串 | 字符串 | 只转换 ASCII 字母 |

示例：

```homo
脱出(取子串("田所浩二", 1))噗叽啪        // 所浩二
脱出(取子串("田所浩二", 1, 2))噗叽啪     // 所浩
脱出(查找("田所浩二", "浩"))噗叽啪       // 2
脱出(查找("田所浩二", "雪"))噗叽啪       // -1
脱出(包含("田所浩二", "浩"))噗叽啪       // 1
脱出(替换("雪雪雪", "雪", "雪（悲）"))噗叽啪
脱出(分割("a,,b", ","))噗叽啪            // ["a", "", "b"]
脱出(连接(["a", 1, 虚无], "-"))噗叽啪    // a-1-虚无
脱出(去空白("  雪  "))噗叽啪             // 雪
脱出(转数字(" 42 "))噗叽啪               // 42
脱出(转数字("3.14"))噗叽啪               // 3.14
脱出(转大写("abcXYZ"))噗叽啪             // ABCXYZ
脱出(转小写("abcXYZ"))噗叽啪             // abcxyz
```

细节与错误：

- `取子串` 的起点可以等于长度（得到空串）；起点越界、长度为负、起点加长度越界都会报
  `取子串越界：起点 X，长度 Y，总长 Z`。
- `替换` 的旧串不能为空；替换后从新串末尾继续，`替换("aa", "a", "aa")` 不会死循环。
- `分割` 的分隔符不能为空；开头和结尾的空段会保留。
- `连接` 的第一个参数必须是数组，分隔符和每个元素都必须是标量；`虚无` 会拼成文本 `虚无`。
- `转数字` 会先去掉两端 ASCII 空白，并要求整个字符串都是合法数字；`"12abc"`、`"1e"`、`""` 都会报
  `不是合法的数字：「…」`。
- `转大写` / `转小写` / `去空白` 只处理 ASCII，中文不受影响。
- 参数个数错误在编译期报，例如 `取子串 需要 2 到 3 个参数，但给了 4 个`。

## 输入与输出

### 脱出

`脱出` 只接受一个参数，只能作为独立语句，并以 `噗叽啪` 结尾；输出后自动换行。

```homo
脱出("年龄：{年龄}")噗叽啪
脱出(某个值)噗叽啪
脱出("{a} + {b} = {a + b}")噗叽啪
```

- 当参数是**字符串字面量**时，`{表达式}` 会被当作模板：先计算表达式，再把结果拼进文本。
- 模板里的表达式可以调用函数、取下标、取字段等。
- 模板里不能嵌套另一层带引号的字符串字面量；需要时先存进变量。
- 参数不是字符串字面量时（例如变量、数组、数字），整体按打印规则输出，不做模板替换。
- 数组和对象会按结构展开打印。

### 读入

```homo
你是一个一个一个 n 事 读入() 罢
```

读取一个整数（底层是 `scanf("%lld")`），会跳过前面的空白。读到非数字或 EOF 时返回 0。

### 读行

```homo
你是一个一个一个 行 事 读行() 罢
```

跳过行首的空格、制表符、回车和换行，读取到行尾，并去掉末尾的 `\r`。EOF 时返回空串。因为行首空白会被跳过，不能用来保留缩进。

在 Web 编辑器里运行时，下方输入条可以把每一行实时送给正在运行的程序。

## 编译工具链

`homo.py` 的处理流程：

```
词法分析 → 语法分析 → 名字与作用域检查 → 类型推导 → 生成 C++
```

生成 C++ 后：

- 在 `g++`、`clang++`、`c++` 中按顺序查找可用编译器。

- 临时构建目录会写入 `main.cpp` 和 `homo_runtime.hpp`。
- `--keep` 可以保留目录，便于查看生成的 C++。

## 已知限制

- 字符串字面量不能跨行。
- 数组和对象变量在条件、`且`、`或` 里恒为假；数组字面量直接用作条件会编译失败。请显式比较。
- 数组和对象参与算术会退化成 0，结果没有意义。
- 比较只有 `<` 和 `==`，其余用 `迫真` 组合。
- 没有继承、接口、异常、模块系统；`import` 是空操作。
- `读行` 会跳掉行首空白。
- `--run` 在非交互环境下不转发标准输入。
- 方法参数个数在运行期检查。
- 数字字面量只支持十进制整数和小数，不支持指数、十六进制。

## 完整示例

下面这个程序覆盖了类、构造函数、可变参数、区间循环、分割、连接、字符串下标和模板输出，可以用 `python3 homo.py 示例.homo --run` 直接运行：

```homo
import homocore

类 计数器 {
    你是一个一个一个 总数 事 0 罢

    首(初值){
        总数 事 初值 罢
    }

    加(n){
        总数 便加 n 罢
        (总数)人幸终
    }
}

求和(一坨 数){
    你是一个一个一个 总 事 0 罢
    (长度(数))回啊(长度(数))回{
        总 便加 数[回数] 罢
    }
    (总)人幸终
}

会员制餐厅(){
    你是一个一个一个 计 事 新建 计数器(10) 罢
    脱出("加 5 次后：{计.加(5)}")噗叽啪

    你是一个一个一个 词 事 分割("苹果，香蕉，雪", "，") 罢
    (长度(词))回啊(长度(词))回{
        脱出("{回数}：{词[回数]}")噗叽啪
    }
    脱出(连接(词, " / "))噗叽啪

    你是一个一个一个 字 事 "田所浩二" 罢
    脱出("首字：{字[0]}")噗叽啪
    脱出(求和(1, 2, 3, 4))噗叽啪
    (0)人幸终
}
```

输出：

```

2：雪

```
